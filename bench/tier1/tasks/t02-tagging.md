We want to be able to tag projects so they can be grouped across teams. A tag has a name
and should be reusable across many projects, and a project can carry several tags. Tag
names should be unique and case-insensitive — "Backend" and "backend" are the same tag.
The projects index should accept an optional tag filter so you can ask for just the
projects carrying a given tag. Include tests for the model relationships and the filtering.
