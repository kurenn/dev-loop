A development loop that stops when the work isn't ready.

Plan, critique the plan, implement in parallel, then refuse to ship past a gate that isn't a vibe check. Any stack. One command.

The gate

✓Mechanical checks green against a pre-change baseline. Coverage may not fall.
✗Zero blocking findings — a severity, not a score.
✓Every major finding fixed, or waived with a written reason.

Install

# once
/plugin install dev-loop@kurenn
/dev-loop-setup          # detects and verifies this repo's commands

# then, per feature or bug
/dev-loop add tagging to projects
