dev-loop

A development loop for Claude Code that won't ship while anything is blocking.

▄▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁▁

  • Plans with fable, then critiques the plan with a second fable that never saw the first.
  • Implements in parallel with sonnet agents, each owning a disjoint set of files.
  • Gates on build, test, lint, typecheck and coverage before spending on review.
  • Reviews adversarially with Codex, then rates with a threshold-blind opus.
  • Ships on zero blocking findings — a severity, not a score.
  • Any stack. Setup detects and verifies your project's own commands.
